# docs — Documentação do projeto

| Arquivo | Conteúdo | Quando atualizar |
|---|---|---|
| `escopo.md` | Objetivo geral e específicos, premissas, o que está fora do escopo e critérios de conclusão | Se o grupo mudar o recorte do projeto |
| `indicadores-dashboard.md` | KPIs de negócio e de desempenho do modelo, por página do dashboard | Ao incluir ou remover um indicador |
| `dicionario-de-dados.md` | Colunas da base bruta, do dataset tratado e das saídas do modelo | Assim que a base for escolhida e a cada nova feature |
| `plano-de-atividades.md` | Etapas, responsáveis, prazos e status | Toda reunião de acompanhamento |

Esta pasta é a fonte de verdade do projeto: antes de abrir uma discussão sobre
"o que a gente combinou", confira aqui. Se a resposta não estiver documentada,
o próximo passo é documentá-la.
